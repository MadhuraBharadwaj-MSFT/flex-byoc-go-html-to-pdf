# Support

This repository contains a preview sample and is provided as-is.

- Use GitHub issues for reproducible problems in the sample source or
  documentation.
- Use [Azure Support](https://azure.microsoft.com/support/) for Azure service,
  subscription, quota, billing, or preview-enablement issues.
- Use the [Azure Functions documentation](https://learn.microsoft.com/azure/azure-functions/)
  for supported product guidance.

Do not include credentials, subscription or tenant IDs, customer data, internal
resource names, or personal information in an issue.
